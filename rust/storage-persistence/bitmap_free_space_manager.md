A fixed-capacity block allocator backed by a bool bitmap: allocate() returns the lowest
free index (first-fit) and marks it used, free(addr) releases it, and a running
free_count tracks availability. Use to manage a bounded pool of slots (disk blocks,
buffer frames) where the first free slot is wanted and reuse is expected.
Guarantees no double-allocation (a used slot is never handed out twice), that free() of
an out-of-range or already-free address is a rejected no-op returning false (no
over-free), and that free_count stays exact across alloc/free cycles.
Bitmap free-space manager: alloc/free via bitmap.
No double-allocate, exact free count.
