Stack-based checker for balanced (), [], {} that is string-aware.
It pushes openers and matches closers against the stack top, but while inside a double-quoted
string it ignores brackets entirely and honours backslash escapes (so \" does not end the string).
Use to validate delimiter nesting in source/config text where quoted literals may contain brackets.
Guarantees: returns Ok(true) only when every bracket is matched in the right order; returns Err on
a mismatched closer, an unclosed opener, or an unterminated string (a naive counter would miss these).
