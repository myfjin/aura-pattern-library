## New findings in v1.6

### N1 — R3 degenerate_equal is over-broad → false-FLAG

**Synthetic test:** `def mean(a: float, b: float) -> float: return (a+b)/2`
**Tool verdict:** `FLAG [accept=3 reject=4]`
**Reasoning:** R3 makes `a == b` by copying the first numeric param into the second. For `mean`, equality is valid input, not invalid. The generic executor counts any finite output as "silent domain acceptance" and flags the pattern.
**Impact:** Any pattern whose function is symmetric or whose numeric params are not a contrast will be false-FLAGed at scale. This inflates the 328 FLAG count with healthy patterns.
**Suggested fix:** Gate R3 on param-name contrast (e.g., pairs containing `p1/p2`, `rate_a/rate_b`, `successes/trials`, `n1/n2`, `a/b`, or params whose names suggest comparison). Do not fire on arbitrary numeric pairs.

### N2 — cross-param impossible (R4 / E004) still missing

**Pattern:** `bayesian_ab_beta.py` — params `successes_a, trials_a, successes_b, trials_b`.
**Current fixtures:** R1, R2, R3, R5, R6, R8, R9. No R4.
**Hand-audit finding:** `successes_b=65, trials_b=10` is silently accepted and produces confident wrong output.
**Tool verdict at scale:** Depends on hand probe via `judge()` — so it is INVALID. But if judged only by generic executor, R4 is missing.
**Suggested fix:** Add generic R4 detection: for any pair of params where one name contains `successes/count/k` and another contains `trials/n/total`, fire `successes > trials`. Also handle `lengths` mismatch for parallel arrays.

### N3 — shape-mismatch (R7 / E007) still missing

**Pattern:** `stacking_ensemble.py` has parallel arrays `X` and `y`.
**Current fixtures:** no unequal-length mutation for collections.
**Hand-audit finding:** `y` one element longer/shorter silently trains a corrupted model.
**Suggested fix:** For any two collection params, generate mismatched-length versions in both directions.

### N4 — DOMAIN_ATTACKS does not cover suffixed/prefixed names

**Example:** `alpha_prior`, `alpha_range`, `beta_prior`, `p_value`, `mean_diff`, `success_rate`.
**Current behavior:** `_domain_values('alpha_prior')` returns `[]`. The heuristic only matches exact names or names ending with `_{name}`.
**Impact:** Many real-world param names won't get domain-aware attacks.
**Suggested fix:** Use token/substring matching (any name containing `alpha`, `rate`, `prob`, etc.), with a deny-list for unrelated words.

### N5 — complex / unannotated types cause SKIP

**Observation:** 4 of the first 50 python DS files have no type-annotated entry functions and thus SKIP in the generic executor. Even with hand probes, this limits scale coverage.
**Examples:** `bayes_factor_normal_means.py`, `elbo_monotone_vi.py`, `posterior_contraction_rate.py`, `mediation_effects_decomposition.py`.
**Suggested fix:** Add a fallback baseline builder that uses `inspect.signature` defaults + docstring examples, or mark such patterns as `NEEDS_MANIFEST` rather than `SKIP`.

### N6 — numeric-oracle (R10), invariant-stress (R11), mutation (R12), state-sequence (R13) not wired

The generic executor remains a partial recipe implementation. Patterns with wrong-math but no hand probe will be missed at scale; patterns with validation-theater, coverage gaps, or stateful bugs require the missing recipes.

## Summary

v1.6 is materially better than v1.5: the hybrid judge, domain-aware attacks, and concurrency cap are real fixes. But the generic executor now has a new false-positive path (R3 over-broad) and still lacks the full recipe set. The honest 328 FLAG count likely contains many false-FLAGs from R3 and possibly misses real bugs from missing R4/R7.

## Proposals for v1.7

1. Gate R3 on param-name contrast to kill false-FLAGs.
2. Add R4 cross-param impossible and R7 shape mismatch to the generic executor.
3. Extend DOMAIN_ATTACKS with substring matching and a larger catalog of semantic domains (mean, std, df, n/p, mu/sigma, k/n, etc.).
4. Fallback baseline builder for unannotated functions.
5. Wire R10–R13 where generically feasible (numeric oracle for closed-form math requires manifest metadata; R12 mutation can be a per-file static check for now).
