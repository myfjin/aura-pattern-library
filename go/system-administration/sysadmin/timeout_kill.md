# timeout kill

**Language:** Go · **Oracle sphere:** system-administration (this file is the Go twin) · **Category:** Wave 7 · Scheduling & jobs

## What it does

runWithTimeout runs a subprocess under a context deadline, capturing stdout/stderr
and elapsed time: if the process exceeds the timeout it is killed and returns -1,
otherwise it returns the real exit code. Use it to bound external commands so a
hung child can never block the caller indefinitely. The oracle proves a 10s sleep
under a 0.5s timeout is killed promptly (returns -1, well under the wall limit)
while fast commands complete and return their normal exit code and output.
