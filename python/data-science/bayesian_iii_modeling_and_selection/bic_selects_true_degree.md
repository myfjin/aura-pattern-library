# bic selects true degree

**Language:** Python · **Sphere:** data-science · **Category:** Bayesian III — Modeling & Selection

**Signature:** `(x: List[float], y: List[float], degree: int) → float`

## What it does

BIC model selection picks the true polynomial degree.

Fits polynomials of increasing degree by real least squares (Vandermonde normal equations
solved with Gaussian elimination) and scores each with BIC = n·log(RSS/n) + k·log(n). BIC
penalizes the extra parameters of over-fit models, so it selects the TRUE degree.
Core claim: on data generated by a degree-1 model, argmin BIC == 1.

## Guarantee

When it runs, bic selects true degree guarantees best_degree == 1; scores[2] > scores[1] and scores[3] > scores[1] (weak-grade: directional, proven by run).

**Checkable constraints:**

- `best_degree == 1`
- `scores[2] > scores[1] and scores[3] > scores[1]`
